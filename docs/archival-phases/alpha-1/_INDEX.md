# Alpha-1 — Documentation Index

This index explains **how to read the Alpha-1 public documentation** and how the documents relate to one another.

Alpha-1 is a **frozen phase**.  
All documents listed here are permanent reference points.

---

## Reading Order (Recommended)

For a complete understanding of Alpha-1, read the documents in this order:

1. **README.md**  
   High-level overview of what Alpha-1 establishes and why it matters.

2. **system-architecture.md**  
   Describes the structural shape of the system and responsibility boundaries.

3. **system-blueprint.md**  
   Explains the conceptual flow of information through the system.

4. **limitations.md**  
   Defines explicit non-guarantees and boundaries of Alpha-1.

5. **roadmap.md**  
   Clarifies what Alpha-1 unlocks and how it fits into future phases.

---

## Document Responsibilities

Each document has a distinct purpose:

- `README.md`  
  Explains **what Alpha-1 is**.

- `system-architecture.md`  
  Explains **how the system is structured** at a high level.

- `system-blueprint.md`  
  Explains **how information conceptually moves** through the system.

- `limitations.md`  
  Explains **what Alpha-1 does not claim or guarantee**.

- `roadmap.md`  
  Explains **how Alpha-1 relates to future phases**.

No document duplicates another’s responsibility.

---

## Precedence Rules

If any ambiguity or perceived contradiction arises:

1. **Limitations override interpretation**  
   If something is not guaranteed in `limitations.md`, it must not be assumed.

2. **Architecture overrides flow assumptions**  
   Structural boundaries take precedence over conceptual flow.

3. **Blueprint explains intent, not mechanics**  
   The blueprint must not be read as an implementation guide.

4. **Roadmap does not redefine Alpha-1**  
   Future direction never alters what Alpha-1 establishes.

## Scope Reminder

These documents intentionally exclude:

- internal implementation details
- agent designs or logic
- data models or schemas
- vendor or tooling choices
- operational failures or experimentation

Alpha-1 public documentation describes **what is true**, not **how it was built**.
