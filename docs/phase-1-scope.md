# PHASE 1 SCOPE – AFTER SALES INTELLIGENCE

## IN SCOPE:

- Manual or seeded signal ingestion
- Issue classification and confidence tagging
- Contact discovery and validation (static)
- User guidance based on known cases
- Read-only backend APIs
- No authentication
- Limited dataset (few brands, few regions)

## OUT OF SCOPE:

- Live web scraping
- Real-time monitoring
- User accounts or profiles
- Monetization
- Legal advice or escalation
- Brand scoring or ranking
- Automated enforcement actions

## SUCCESS CRITERIA:

- System can explain known after-sales issues clearly
- Confidence levels are preserved end-to-end
- System can explicitly say “insufficient data”
- No hallucinated guidance
